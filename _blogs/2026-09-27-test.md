# 第一篇测试日志

这是博客页面的第一篇测试文章。

这里可以记录学习笔记、项目进展、比赛经历，或者一些值得留下来的想法。列表页会把每篇日志显示成统一大小的卡片，点击卡片后就能进入这个独立阅读页面。

## 为什么增加日志页

相比把所有内容都放在主页，日志页更适合持续记录。每篇文章都有自己的地址，也方便以后分享、补充和整理。

后续可以继续在 `_blogs/` 目录下新建 Markdown 文件，写好标题、日期和摘要后，它就会自动出现在日志列表中。

# My First Test Blog

This is the first test post for the new blog page.

The page can hold study notes, project updates, contest experiences, or any idea worth keeping. Each post appears as a card with a consistent size, and clicking a card opens this standalone reading page.

## Why add a blog page

A separate blog keeps the homepage focused while making longer notes easier to organize. Every post has its own URL, so it can be shared and extended later.

To add another post, create a Markdown file in `_blogs/`, add its title, date, and excerpts, and it will appear in the blog list automatically.
